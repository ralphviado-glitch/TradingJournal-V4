# Database Structure

This document reflects the schema the frontend expects from Supabase. Remote schema verification is still required before applying migrations in production.

## Tables

### `trades`

Private user-owned trading records. Frontend queries always filter by `user_id = auth user id`.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid | Primary key. Generated by database. |
| `user_id` | uuid | Required. References `auth.users(id)`. Ownership field for RLS. |
| `trade_date` | date | Required by frontend. Mapped to `trade.date`. |
| `ticker` | text | Required by frontend. |
| `direction` | text | Expected values: `Long`, `Short`. |
| `entry_time` | text | New York formatted display time from CSV. |
| `exit_time` | text | New York formatted display time from CSV. |
| `entry_price` | numeric | Required by frontend calculations. |
| `exit_price` | numeric | Required for completed trades. |
| `shares` | numeric | Supports decimal quantities. |
| `pnl` | numeric | Realized P&L. |
| `risk` | numeric | Optional, defaults to `0`. |
| `setup` | text | Defaults to `Unclassified`. Editable. |
| `notes` | text | Editable journal notes. |
| `grade` | text | Editable setup grade. |
| `mistake_tags` | text[] | Editable mistake tags. Mapped to `mistakeTags`. |
| `emotion_tags` | text[] | Editable emotion tags. Mapped to `emotionTags`. |
| `rules_followed` | boolean | Editable rules-followed flag. Mapped to `rulesFollowed`. |
| `orders` | jsonb | Source order breakdown from CSV reconstruction. |
| `screenshot_path` | text | Private Supabase Storage object path for new screenshots. |
| `screenshot_url` | text | Legacy/public/base64-compatible screenshot field. Keep for backward rendering. |
| `created_at` | timestamptz | Expected timestamp. |
| `updated_at` | timestamptz | Updated by frontend on trade edits. |

Useful indexes:

- `(user_id, trade_date)`
- `(user_id, ticker)`

### `market_days`

Private user-owned daily market context records. Frontend queries always filter by `user_id = auth user id`.

| Column | Type | Notes |

| `user_id` | uuid | Required. References `auth.users(id)`. Ownership field for RLS. |
| `trade_date` | date | Required. Unique per user with `user_id`. |
| `market_condition` | text | Required by form. |
| `spy_bias` | text | Required by form. |
| `spy_pdh` | numeric | Optional. |
| `spy_pdl` | numeric | Optional. |
| `spy_pmh` | numeric | Optional. |
| `spy_pml` | numeric | Optional. |
| `spy_liquidity_target` | text | Optional. |
| `qqq_bias` | text | Required by form. |
| `qqq_pdh` | numeric | Optional. |
| `qqq_pdl` | numeric | Optional. |
| `qqq_pmh` | numeric | Optional. |
| `qqq_pml` | numeric | Optional. |
| `qqq_liquidity_target` | text | Optional. |
| `event_type` | text | Optional. |
| `event_name` | text | Optional. |
| `notes` | text | Optional. |
| `created_at` | timestamptz | Expected timestamp. |
| `updated_at` | timestamptz | Expected timestamp. |

Expected constraint:

- Unique `(user_id, trade_date)` for market-day upserts.

## Storage

Bucket: `trade-screenshots`

Expected privacy: private bucket.

New screenshot paths use:

```text
{user_id}/{trade_id}/{timestamp}-{uuid}.{extension}
```

The database stores `screenshot_path`, not base64 data, for new uploads. Existing base64/public URL screenshots in `screenshot_url` are preserved and rendered for backward compatibility.

## RLS

Prepared migration: `supabase/migrations/202608100001_phase1_stabilization.sql`

Expected policy principle for all private tables:

```sql
auth.uid() = user_id
```

The migration enables SELECT, INSERT, UPDATE, and DELETE policies for `trades` and `market_days`, including `WITH CHECK` on INSERT and UPDATE so ownership cannot be changed to another user.

Storage policies restrict `trade-screenshots` objects to paths whose first folder segment equals the authenticated user's id.
